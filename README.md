### 01. Tacoma Tideflats Closed Landfill GIS and Cross-Section Automation

> **Environmental database development, QA/QC, subsurface modeling, and ArcPy automation**

<div align="center">

![ArcGIS Pro](https://img.shields.io/badge/ArcGIS_Pro-2C7AC3?style=flat-square&logo=esri&e
![Pythonimg.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white

I developed an integrated GIS database and automated mapping workflow for historical
environmental information associated with the former Tacoma Tideflats closed landfill.

The completed inventory contains **336 investigation locations**, including boreholes,
monitoring wells, test pits, probes, and soil borings. Records from environmental
investigations, parcel reports, historical inspections, methane monitoring, and
cleanup-site resources were consolidated into a traceable geospatial framework.

#### Project impact

- Standardized investigation identifiers, contaminant descriptions, depth measurements,
  analytical results, and site-status categories
- Connected investigation locations to available sampling-depth intervals
- Preserved source-document references and data-match confidence
- Used composite identifiers to reduce incorrect joins caused by reused location names
- Distinguished exceedances, lower-level detections, landfill material, and missing
  analytical information
- Prevented locations without analytical results from being incorrectly interpreted as clean
- Avoided extending a result from one sampling depth through an entire boring

#### Cross-section automation

I developed Python and ArcPy workflows that automatically:

1. Process cross-section lines
2. Select nearby investigation locations
3. Calculate each location's station along the section
4. Parse and validate available depth intervals
5. Generate separate maps for sections **XS_A through XS_E**
6. Create ground-surface lines, investigation points, depth sticks, interval bands,
   label anchors, grid lines, axes, and labels
7. Apply configurable vertical exaggeration and automated symbology

The automation incorporates:

- Flexible field-name matching

- Spatial-reference validation
- Configurable section-selection distances
- Configurable vertical exaggeration
- Automated feature-class creation
- Automated symbology
- Detailed error and status messages

I also created a depth-based concentric-buffer workflow that generates polygon rings at
three-foot increments. The cross-section framework was designed so that additional
measurements, including methane readings, can be incorporated as value-based interval
overlays.

> **Repeatable drone monitoring, temporal comparison, and GeoAI-assisted change detection**

I developed an ArcGIS Experience Builder application that supports long-term shoreline
monitoring across the Port of Tacoma.

The monitoring program uses predefined drone flight locations and automated flight
schedules so imagery can be collected from consistent positions and viewing angles.
This creates a stronger foundation for comparing shoreline conditions over time.
