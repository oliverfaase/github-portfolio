Shoreline OIC Experience Builder

Project Overview

I developed an ArcGIS Experience Builder application supporting long-term shoreline monitoring throughout the Port of Tacoma.

The application organizes monitoring locations, repeatable drone imagery, environmental conditions, and multiple monitoring periods in a centralized spatial interface.

Project Contributions

  • Developed an interactive shoreline-monitoring application
  • Organized locations in a centralized GIS platform
  • Integrated repeatable drone imagery
  • Supported year-over-year shoreline comparison
  • Structured imagery for consistent temporal analysis
  • Incorporated GeoAI-assisted comparison workflows
