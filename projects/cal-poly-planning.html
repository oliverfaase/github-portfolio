Project Overview

I created a GIS database and interactive StoryMap to organize, map, and showcase past Cal Poly City and Regional Planning studio projects.

Historical studio records were cleaned, standardized, geocoded, and transformed into a searchable spatial resource.

Project Media

Interactive planning history and studio-project StoryMap.

Project Contributions

  • Compiled historical planning-studio records
  • Cleaned and standardized project attributes
  • Geocoded projects by location
  • Created a structured and searchable GIS database
  • Categorized projects by topic, year, and program level
  • Developed an interactive ArcGIS StoryMap
  • Presented the project to university stakeholders

Project Value

The project gives prospective students, alumni, faculty, donors, and community partners an accessible way to explore the program’s geographic reach and real-world planning impact.
